🎮 Importer dans le jeu

  1. Lance le client League of Legends (connecté).
  2. Ouvre PowerShell : Win + X → « Terminal » (ou tape PowerShell dans le menu Démarrer).
  3. Clique sur Copier le script, colle-le dans PowerShell (Ctrl + V ou clic droit) puis Entrée.
Windows uniquement. Le script parle seulement à ton client LoL, sur ton PC (API locale du client, comme Porofessor ou Blitz). Il crée une page de runes « Team Bravery » et un set d'objets pour ce champion (visible dans la boutique en jeu) ; il remplace les anciens « Team Bravery ». Pendant la sélection des champions, il règle aussi tes sorts d'invocateur.
